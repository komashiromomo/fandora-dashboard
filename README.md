# Fandora 工作日誌 Dashboard

互動式工作日誌分析儀表板，涵蓋 2025年9月 至 2026年1月的工時資料。

## 功能

- **總覽**：KPI 卡片、每月工時趨勢、Top 10 任務、部門分布圓餅圖
- **員工分析**：員工篩選、個人月度工時、雷達圖、全員堆疊面積圖
- **任務分析**：Top 20 任務排行、Top 10 任務月度趨勢折線圖
- **部門分析**：部門篩選、部門 vs 員工工時、人員配置明細表

## 啟動方式

```bash
# 1. 安裝依賴
npm install

# 2. 啟動開發伺服器
npm run dev

# 3. 瀏覽器會自動開啟 http://localhost:3000
```

## 建置生產版本

```bash
npm run build
```

產出的靜態檔案會在 `dist/` 資料夾中。

## 技術棧

- React 18
- Recharts (圖表)
- Vite (建置工具)
